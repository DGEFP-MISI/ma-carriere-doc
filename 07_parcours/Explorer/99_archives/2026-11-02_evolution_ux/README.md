# Évolution UX ciblée — 2 novembre 2026

Le socle de données existant est conservé et l'organisation de l'expérience est revue selon [le retour utilisateur](../../12_maquette_html/documentation/RETOUR_UX_UTILISATEUR.md).

- ETAT_AVANT.zip : fichiers actifs avant évolution, sans dupliquer les anciennes archives ni les traces volumineuses.
- INVENTAIRE_AVANT.json : empreintes de l'état d'entrée.
- préparer/appliquer/ajuster/finaliser_sources/actualiser_documents : scripts de journal des transformations, déjà exécutés. Ils ne sont pas des commandes à relancer pour ouvrir le parcours.
- [Vérification](VERIFICATION_EVOLUTION.json) : intégrité des références, conservation des appels et contrôles locaux actuels.

La maquette actuelle est [index.html](../../12_maquette_html/index.html). [L'évolution et ses limites](../../12_maquette_html/documentation/EVOLUTION_STRUCTURE_UX.md) distinguent le prototype autonome, la future intégration HTTP et les autres parcours à raccorder plus tard selon la demande de l'utilisatrice. Les captures locales ne prouvent ni les appels HTTP réels ni une conformité RGAA.
