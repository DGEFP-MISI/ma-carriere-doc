# Rangement du 2 novembre 2026

Le rangement est limité au dossier Explorer. Les livrables 01 à 10 conservent leurs noms. Les sources contractuelles, JSON observés, UML et contrôles API hors Explorer ne sont ni déplacés ni réécrits.

- [Inventaire avant rangement](INVENTAIRE_AVANT.json) : chemins et empreintes des fichiers préexistants.
- [Mouvements](DEPLACEMENTS.json) : 24 déplacements explicites, certains portant sur un dossier entier.
- [Livrables L0 avant actualisation](LIVRABLES_L0_AVANT_MISE_A_JOUR.zip) : les dix fichiers de travail dans leur état d'entrée.
- reorganiser.py et actualiser_documents.py : journal exécutable des transformations déjà appliquées ; ne pas les relancer pour consulter le parcours.
- [Vérification du rangement](VERIFICATION_RANGEMENT.json) : intégrité, liens, couverture et invariants API après rangement.

Les premiers rendus sont conservés dans [les archives UX/UI](../../11_ux_ui/archives/conception_initiale/README.md), les anciens textes et scripts dans [les archives HTML](../../12_maquette_html/archives/README.md). Aucun fichier préexistant n'a été supprimé ; les fichiers actifs réécrits sont identifiés par le journal. Les documents historiques peuvent contenir d'anciens chemins et nombres de contrôles, qui ne sont plus les consignes actuelles.

La maquette à consulter est [index.html](../../12_maquette_html/index.html), avec [son guide actuel](../../12_maquette_html/README.md). Le HTML reconstruit après déplacement a la même empreinte qu'avant rangement : le nettoyage ne change pas la présentation citoyenne.
