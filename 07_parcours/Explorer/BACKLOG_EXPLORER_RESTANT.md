# Explorer — travaux restant à traiter

2 novembre 2026. Les 31 fonctionnalités E01–E31 restent dans le périmètre. Ce tableau complète le suivi existant ; aucune ligne ne constitue une proposition de suppression.

Le [backlog fonctionnel de référence](04_BACKLOG_USER_STORIES.md) décrit désormais les 31 fonctionnalités et quatre exigences transversales, avec les dix rubriques, scénarios et SVG. Le présent fichier suit les travaux restant dans le prototype : il ne remplace pas cette couverture complète. Les liens entre US, mesures, API et critères figurent dans ses matrices.

| Priorité | Sujet | Travail attendu | Dépendance / validation |
|---|---|---|---|
| P0 — recette | Rechargement natif après navigation par fragments | Vérifier manuellement Ctrl+R/F5 avec trois pistes, puis après un retrait. Le pilote Edge n’a pas confirmé ce rechargement ; la reprise de session après deux nouveaux chargements complets est, elle, testée. | QA ; voir le statut NON TESTÉ du rapport navigateur. Ne pas confondre les deux vérifications. |
| P0 — recette | Zoom navigateur, lecteurs d’écran et accessibilité complète | Compléter les tests au vrai zoom navigateur 200/400 %, avec lecteur d’écran, puis mener l’audit RGAA. Grossissement visuel CDP, reflow 640/320 px, clavier et échantillon de contrastes sont déjà contrôlés. | QA accessibilité ; les contrôles actuels ne certifient pas la conformité du service. |
| P0 — données | Savoir-faire, domaines et contextes combinés | Collecter les réponses manquantes avec les GET déjà documentés. Les mobilités restent des flux entre groupes statistiques. Les réponses disponibles ne donnent pas de code métier de destination : aucun lien de flux vers une fiche n’est inféré d’un libellé. Les métiers proches disposent de liens distincts, fondés sur les références réellement reçues.
